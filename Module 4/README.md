# Module 4: Decoupling Code and Feature Releases

This folder contains code samples from Module 4 of the course. The [Store API with Feature Flags](store-api-feature-flags/) demonstrates how configuration can control a feature independently of deployment.

These samples are provided *out of context* for review and practice. In the ONF course, all of these topics are introduced step by step, explained in detail, and supported with work requirements for hands-on experience.
