# Code Samples - PRO2004 DevOps and Cloud Computing

This repository contains code samples from the course **[PRO2004 DevOps and Cloud Computing](https://onf.qybele.no/structure/module/overview/259.html)**.

One small store API is used throughout the course to demonstrate Azure hosting, CI/CD, security, releases, and Infrastructure as Code.

- [Demo app](demo-app/): Python API with mock data and a Dockerfile for local use.
- [Module 1](Module%201/): Azure cloud fundamentals and Free (F1) Web App setup.
- [Module 2](Module%202/): CI/CD and GitHub Actions (draft).
- [Module 3](Module%203/): DevOps security practices (draft).
- [Module 4](Module%204/): Feature flags and releases (draft).
- [Module 5](Module%205/): Bicep and Terraform structure (draft).

Azure deployment uses App Service Free (F1) with a built-in Python runtime. Docker is used locally. Examples are intentionally small and are explained in context in the course.
