# Module 5 - Infrastructure as Code (Draft)

Both tools will describe the same Azure resources for the shared store API. Choose one tool to manage an exercise environment.

- [Terraform](terraform/): equivalent definitions, state, and lifecycle exercises.

Start with a resource group, then add an F1 plan and Web App. These folders are placeholders; no infrastructure is deployed by this draft.
